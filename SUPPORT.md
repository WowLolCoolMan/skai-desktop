# Support

Skai Desktop is an actively developed project, not a paid support service.
There is no guaranteed response time.

- For setup and usage, start with the [README](README.md) and
  [documentation index](docs/INDEX.md).
- For a reproducible defect, use the **Bug report** issue form.
- For a proposed capability, use the **Feature request** issue form and check
  [To Do Next](docs/TO_DO_NEXT.md) and the [capability matrix](docs/CAPABILITY_MATRIX.md).
- For an accessibility barrier, use the **Accessibility barrier** issue form.
- For a suspected security vulnerability, follow [SECURITY.md](SECURITY.md) and
  do not post it publicly.

Please remove conversation content, credentials, tokens, personal data, and
private local file paths from reports. Support cannot recover local app data or
access your computer.
