# Security policy

## Supported versions

Security fixes are developed for the latest release on the current `0.1.x`
release line. Earlier releases may not receive fixes; upgrade to the latest
release when possible.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.
Submit it through GitHub's private vulnerability reporting form:

https://github.com/WowLolCoolMan/skai-desktop/security/advisories/new

If GitHub does not offer the private reporting form, contact the repository
owner through the private contact options on https://github.com/WowLolCoolMan.
Include a clear description, affected versions, impact, and steps to reproduce.
Do not include real user data, credentials, or secrets.

The maintainers will acknowledge reports as soon as practical, investigate in
private, and coordinate a fix and disclosure with the reporter. Please allow
time for a fix before public disclosure.
